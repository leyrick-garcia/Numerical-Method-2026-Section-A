Fitted curve

Model: h(t) = c + a₁/(1 + exp(-k₁(t − t₀₁))) + a₂/(1 + exp(-k₂(t − t₀₂)))

The double-logistic model was selected because the supplied record contains a rapid rise followed by recession/settling. A single rising logistic or Gompertz cannot represent that full shape; the second logistic term is therefore given a negative amplitude.

Initial guess p₀: [14, 8, 0.5, 31, −4, 0.3, 38]. These values come from approximate baseline, rise size, steepest-rise timing, and later recession timing visible in the raw plot.
